# Solutions

This directory mirrors `lessons/` one folder per lesson and holds the **reference
solutions** for each practical: completed notebooks and example deliverable reports.

```
solutions/
├── lesson01_biological_question/   # Section 1 — project specification
├── lesson02_baseline_model/        # Section 2 — baseline model report
├── lesson03_feature_engineering/   # Section 3 — feature engineering notebook
├── lesson04_model_validation/      # Section 4 — model comparison report
└── lesson05_research_grade_ml/     # Section 5 — research-style report + pipeline
```

Each lesson folder contains:

- `notebooks/` — completed reference notebook (`lessonNN_solutions.ipynb`)
- `reports/`   — example deliverable (specification / report)
